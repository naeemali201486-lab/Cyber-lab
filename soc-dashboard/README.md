# Cyber Lab SOC Dashboard

Local Security Operations Center dashboard for monitoring Cyber Lab services.

## Service

- Host: 127.0.0.1
- Port: 9099

## Endpoints

- `/` — SOC Dashboard web interface
- `/api/status` — JSON service status
- The dashboard monitors six local lab services.

## Status

The dashboard reports:

- Online services
- Offline services
- HTTP status
- Overall health

## Security

This dashboard is intended for a local Cyber Lab practice environment.
